# Changelog

## 0.1.0

- Cronometer mobile REST API client with read and write, from [rwestergren/cronometer-api-mcp](https://github.com/rwestergren/cronometer-api-mcp)
- Streamable HTTP transport, loopback only
- OAuth 2.1 authorization server with PKCE, dynamic client registration and static bearer token
- systemd units, nginx site and installer
